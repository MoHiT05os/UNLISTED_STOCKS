Grey Market Premium is NOT published by:

- NSE
- BSE
- SEBI

There is NO official API.

It comes from:

- Dealer Networks
- Grey Market Traders
- Manual Collection

Hence eventually an Admin Panel is required.

# Why Not Tick-by-Tick?

Website users mainly require:

Approximate market movement

rather than

1-second latency.

Hourly updates reduce:

- Cost
- API usage
- Infrastructure load

# Access Token

During generation:

Application Name

Example:

IPO GMP Website

Token Validity

24 Hours

(or other available duration)

Postback URL

Leave blank initially.

---

# Important Understanding

Access Token

≠

Permanent Key

Access Tokens expire.

Depending on provider:

- Manual regeneration

or

- Refresh mechanism

No broker generally gives a lifetime access token for security reasons.

Never hardcode token inside frontend.

Always store on backend.

Example:

.env

DHAN_CLIENT_ID=

DHAN_ACCESS_TOKEN=

---

# Concern With Broker APIs

Broker APIs are designed mainly for:

Trading Applications

Potential issues:

- Rate Limits
- Authentication expiry
- Licensing restrictions
- Public redistribution limitations

Therefore:

Avoid making Dhan the single dependency.

---

# Better Long-Term Strategy

Use Hybrid Architecture

Daily:

NSE/BSE master data

+

Hourly:

Market Data API

+

Own PostgreSQL

+

Own Backend APIs

This decouples website from provider.

If provider changes:

Only backend changes.

Frontend remains untouched.
